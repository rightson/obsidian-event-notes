# Event Notes 0.3.5

Subscription refreshes now show their progress, and a failed one tells you where it stopped.

- **Progress for every manual sync.** Turning a subscription on or off, the toolbar **Refresh** button, and the **Refresh calendars** command show one notice that names the subscription and its current step: checking the feed URL, fetching the feed, reading the events, updating events and notes, and saving the result. Turning a subscription off shows that its events are being hidden.
- **Turning a subscription on fetches it right away.** It no longer waits for the refresh interval or a retry back-off, so the notice always reflects a real fetch.
- **Success clears itself.** When the sync finishes, the notice says so and closes after a moment.
- **Failures stay until you click them.** The notice lists each subscription that failed, the step it failed at, and the reason. One failing subscription does not hide the others.
- **Background refreshes stay quiet.** Refreshes on window focus, reconnecting, the timer, and moving the visible range show no notice, as before.

## Install

**Download the [Event Notes 0.3.5 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.5/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, `npm test`, and `npm run build` pass. The progress text and step order have automated coverage only and have not had native QA in Obsidian.
