# Event Notes 0.3.7

A wizard changes the Daily Note path rule and moves your existing notes to match, and the settings tab now opens as a short list of folded sections.

- **Change Daily Note folders.** The new wizard works from any Daily Note format to any other, for example from `YYYY/[Q]Q/MM-DD/MMM DD` to `YYYY/MM/MM-DD/MMMM DD`. It previews every file that would move, changes the format (the **Daily fallback format** of Event Notes, or **Date format** of the core Daily notes plugin), then moves the Daily Notes, the Event Notes filed in their folders, and the other files of a day's own folder. Each file is moved the way Obsidian renames a file, so links and embeds to it are updated across the Vault. Files that cannot move safely are listed as skipped and are never overwritten. Open it with **Open wizard** next to **Daily Note folders** under **Note paths** in settings, or run the **Change Daily Note folders** command. It replaces the earlier **Give each day its own folder** suggestion, which changed the format and left existing notes behind.
- **An unfinished move can be finished.** If a move is cancelled, some files are skipped, or you close the wizard before moving, run it again: it remembers the earlier format and moves what is left. Until then, a day whose Daily Note is still at its earlier path keeps using that note, so Event Notes does not start a second Daily Note for it.
- **Folded settings sections.** Settings → **Event Notes** opens as a list of sections, each folded under its heading with a one-line summary of what is set now. Click a heading, or press Enter or Space on it, to unfold it. A section that needs attention, such as a calendar that failed to refresh, shows that in red and opens by itself. Picking a setting in Obsidian's settings search unfolds its section. Open sections are remembered on this device and are not synced.

The wizard does not edit the text of your notes; only links to moved files are updated. The Daily Notes folder itself stays the same.

## Install

**Download the [Event Notes 0.3.7 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.7/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, `npm test`, and `npm run package` pass. Finding the notes to move, planning and resuming a move, and the settings sections' summaries and fold state have automated coverage. The wizard's dialog, the move inside a real Vault, and the folded settings tab have not had native QA in Obsidian.
