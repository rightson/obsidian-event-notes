# Event Notes 0.3.6

One invalid event no longer stops a calendar from refreshing, and a new dialog shows exactly which events were skipped and why.

- **Only the invalid event is skipped.** Previously a single event with invalid data, for example an end that is not after its start, made the whole subscription fail at *Read the events* and nothing was imported. That event, or its whole repeating series, is now skipped and every other event is imported. This also covers an unknown time zone, a missing UID or start, a duplicate UID, and an event whose lines are not valid iCalendar.
- **A changed event keeps its last valid version.** An event that was valid before and becomes invalid stays in the calendar as it was, and its Event Note is not flagged as removed.
- **Calendar import problems.** A new dialog lists, for each subscription, why a refresh failed and each skipped event with its title, the problem, its start and end as written in the feed, and its UID. **Copy as text** copies the list, for example to send to the calendar's owner. Open it from the refresh notice (which now stays open when events were skipped), **Show details** in the calendar's banner, **Import problems…** in a subscription's **Status** in settings, or the **Show calendar import problems** command. The list is kept in memory only and rebuilt at each refresh.

Events whose end is not after their start are skipped and listed; they are not displayed as some calendar apps display them.

## Install

**Download the [Event Notes 0.3.6 ZIP](https://github.com/rightson/obsidian-event-notes/releases/download/0.3.6/event-notes.zip)**, extract it, and copy the `event-notes` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. Moving from Calendar Pro is covered in the [installation guide](https://github.com/rightson/obsidian-event-notes/blob/main/docs/manuals/INSTALLATION.md#moving-from-calendar-pro-or-calendar-note).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. `npm run typecheck`, `npm test`, and `npm run package` pass. Skipping invalid events, keeping the last valid version, and the report's text have automated coverage. The dialog, the banner link, the notice, and the settings button have not had native QA in Obsidian.
